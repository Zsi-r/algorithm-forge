# 统一使用中文

## 语言规则

1. **回复语言**：所有面向用户的回复一律使用中文，不使用英文。
2. **代码注释**：代码中的注释一律使用中文（包括文件头注释、函数注释、行内注释）。
3. **文档文件**：`statement.md`、`solution.md`、`README.md` 等 Markdown 文档一律使用中文撰写。
4. **Commit 信息**：Git commit message 使用中文。
5. **Skill 文件**：`.codebuddy/skills/` 下的 SKILL.md 及 references 文档一律使用中文。

## 例外

- **代码标识符**：变量名、函数名、类名等按编程语言惯例用英文（如 `quick_pow`、`LRUCache`）。
- **技术术语**：通用技术术语可保留英文原文（如 `GraphQL`、`API`、`front-matter`、`snake_case`），不强行翻译。
- **文件路径 / 命令**：文件路径、Shell 命令、代码块保持原样，不翻译。
- **第三方输出**：从外部 API 拉取的原始内容（如 LeetCode 英文题面），保留原文，不做翻译。
